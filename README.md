# DOĞUŞ BOOTCAMP BLOG PROJESİ
Bu proje, Doğuş Bootcamp sürecinde kazanılan bilgi ve beceriler doğrultusunda geliştirilmiş, basit ve işlevsel bir blog yönetim sistemidir. Proje, ASP.NET Core MVC mimarisi, C# dili, ve Entity Framework Core ORM yapısı kullanılarak hayata geçirilmiştir.
# ÖZELLİKLER
Kullanıcının ilk açılış ekranı kayıt ol, giriş yap ve misafir olarak devam seçenekleriyle kullanıcıyı karşılıyor misafir olarak giriş yapan kullanıcılar blog yazısı yazamaz ve yorum ekleyemezler.
Anasayfada gönderimin önceliğine göre gönderiler sıralanır. Kategorilere göre sınıflandırılır. En çok etkileşim alana göre listelenir.
Kullanıcılar profillerinde gönderilerini görüntüleyebilir, düzenleyebilir, silebilir. Hiçbir gönderi admin onayı olmadan yayımlanmaz.
